NAPRAWNIK v5 — projekt Expo

WAŻNE:
App.js nie jest aplikacją APK. To kod źródłowy.

NAJPROSTSZY START NA KOMPUTERZE:
1. Zainstaluj Node.js.
2. W tym folderze uruchom:
   npm install
3. Następnie:
   npx expo start
4. Zainstaluj Expo Go na Androidzie.
5. Zeskanuj kod QR pokazany przez Expo.

START BEZ KOMPUTERA:
Możesz użyć Expo Snack (snack.expo.dev):
- utwórz projekt,
- wgraj App.js,
- dodaj zależność @react-native-async-storage/async-storage,
- uruchom w Expo Go.

To jest pełny projekt aplikacji, ale nie gotowy APK.
